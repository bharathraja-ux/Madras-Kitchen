# Madras Kitchen (மெட்ராஸ் கிச்சன்)

A responsive restaurant website for **Madras Kitchen**, an authentic Chinese restaurant in Kodambakkam, Chennai.

## Key Features
- **Brand Positioning**: *"Great taste. Generous portions. Easy on the pocket."* (₹1–200 per person)
- **Local Hub**: Dine-in, Takeaway & Delivery in Kodambakkam, Chennai.
- **Popular Menu**: Chicken Noodle Soup, Chicken Fried Rice, Hot & Sour Soup, Chilly Chicken, Chicken Mushroom Soup, Veg Corn Soup, Pastas, Gobi Manchurian, and Chicken Noodles.
- **Interactive Filtering**: Filter dishes by category (Popular, Soups, Rice, Noodles, Chicken, Vegetarian, Pasta).
- **Local SEO & Schema.org**: Fully structured Restaurant JSON-LD metadata for Google search indexation.
- **Mobile First**: Thumb-friendly layout, sliding mobile drawer, and floating one-tap call action bar.

## Project Structure
- `index.html` — Semantic HTML5 markup with accessible tags and SEO metadata.
- `styles.css` — Custom CSS3 design system with design tokens, glassmorphic headers, and fluid typography.
- `app.js` — Interactive tab filters, mobile menu controller, and sticky navigation scroll handler.
- `images/` — Curated and bespoke high-resolution culinary photography.

## How to Run Locally
Run any static file server, such as:
```bash
python -m http.server 3000
```
Then visit `http://localhost:3000` in your web browser.
